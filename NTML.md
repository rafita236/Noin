## NTML Documentation

> **Note:** This Documentation assumes you know some HTML

NTML is based in HTML.
## Doctype
This tells what NTML version its written, The current doctype is:

    <!doctype ntml>
## Event attributes

 -   `oc1` - Left Click
    
-    `oc2`  - Right Click
    
-   `oc3` - Scroll Up
    
-   `oc4` - Scroll Down
    
-   `oc5` - Middle Click
## Multiple Line Paragraph
The element `<br>` makes a new line.
 

    <p>This is a example of multiple lines<br>This is the second line
     </br>

   `<br>` isn't self-closing, but `<p>` is self-closing if theres a `<br>` element
